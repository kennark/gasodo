# 🚗 Car Refuel Tracker

A modern Android application built with **Jetpack Compose** for tracking vehicle refueling. Designed to help car owners manage their vehicle's fuel consumption.

## 🎯 Goal & Purpose

The primary goal of this project is to create a comprehensive mobile solution that enables users to:

- **Track Refueling Events**: Log every refuel with details like liters pumped, price per liter, total cost, payment method, and whether it was a full tank
- **Monitor Fuel Consumption**: Calculate and analyze fuel efficiency statistics over time periods
- **Save Locations**: Keep track of gas stations and service providers by location for quick access

## 🛠️ Features

### Core Functionality
- **Refuel Tracking** - Complete fuel event logging with cost analysis
- **Location Saved** - Track gas stations in the refuel events
- **Analytics Dashboard** - View total costs, consumption rates, and mileage statistics

### Technical Features
- Offline-first architecture
- MVVM (Model-View-ViewModel) architectural pattern
- Hilt dependency injection
- Material Design 3 UI components with Material You theming


## 🎨 UI/UX Highlights

- **Overview Screen**: Dashboard with date range selector, total statistics, and fuel consumption metrics
- **Refuel Screen**: Form to add/edit refueling events with validation
- **Add Event Screen**: Unified interface for adding different event types
- **Navigation**: Bottom navigation bar with intuitive category switching
- **Material 3 Design**: Modern, accessible UI components
